# Веб-приложение «Заметки»

## 1. Описание проекта
Веб-приложение для создания и хранения персональных заметок, разработанное в рамках итоговой аттестации по дисциплине «Проектный практикум».

## 2. Основные возможности
* Просмотр списка всех сохраненных заметок.
* Добавление новой заметки с валидацией полей.
* Автоматическое тестирование API.
* Минималистичный встроенный веб-интерфейс.

## 3. Стек технологий
* **Backend:** Python 3, FastAPI, Uvicorn
* **Database & ORM:** SQLite, SQLAlchemy, Alembic
* **Testing:** Pytest
* **Frontend:** HTML5, JavaScript (Fetch API)

## 4. Структура проекта
* `alembic/` — Папка миграций базы данных
* `database.py` — Настройки подключения к БД
* `main.py` — Эндпоинты API и HTML-интерфейс
* `models.py` — Модели данных и схема валидации
* `test_main.py` — Автотесты
* `alembic.ini` — Конфигурация Alembic
* `.gitignore` — Исключения для Git
* `README.md` — Документация проекта

## 5. Переменные окружения проекта
Проект использует локальную базу данных SQLite (`notes.db`). Конфигурация пути подключения задается в параметре `SQLALCHEMY_DATABASE_URL` внутри файлов `database.py` и `alembic.ini`.

## 6. Как запустить проект
1. Клонировать репозиторий: git clone <ссылка_на_ваш_репозиторий>
2. Перейти в папку проекта: cd proekt
3. Создать виртуальное окружение: python -m venv venv
4. Активировать окружение (Windows): venv\Scripts\activate
5. Установить зависимости: pip install fastapi uvicorn sqlalchemy alembic pytest httpx
6. Применить миграции базы данных: alembic upgrade head
7. Запустить сервер: uvicorn main:app --reload
8. Открыть сайт: http://127.0.0.1:8000
